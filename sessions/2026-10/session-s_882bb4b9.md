## Шаг 2. Написать тизеры

Модель — **Fable** (авторский текст, §6.2). Формат v2 (утверждён 27.09, закон с 01.10 —
`reglament-kazhdyy-deep-research-rozhdaet-post-s-polzoy`):

1. **заголовок с пользой** ≤100 знаков — «Провёл глубокое исследование от N ЛЛМ: <что
   читатель получит>». N = реально дошедшие рельсы, из отчёта, не выдумка;
2. **боль → решение** — у нас была такая боль; короткие выводы с цифрой или именем;
3. 240-500 знаков.

⚠️ **ЛИМИТ 240-500 СЧИТАЕТСЯ ПО ВСЕМУ ПОЛЮ, РАСКРЫТИЕ АВТОРСТВА ВНУТРИ** (замер 08.10). Код
гейта берёт `body = t["ru"]` целиком (`dr_teaser_gate.py:99`), то есть раскрытие Майкрофта
(RU 66 знаков, EN 72) и строка-крючок съедают лимит наравне с выводами. Прежняя формулировка
«ссылка и раскрытие в лимит не входят» верна только про ССЫЛКУ: она идёт отдельной строкой при
отправке и в поле не лежит. На этой фразе 08.10 четыре тизера из десяти ушли за 500 с первого
письма. Считай так: **на сами выводы остаётся ~330-420 знаков**, и мерь поле целиком до гейта.

⚠️ **ПОТОЛОК ПОЛЯ `x` — 239 ЗНАКОВ, И ЭТО ТОЖЕ С РАСКРЫТИЕМ.** Арифметика гейта:
`X_HARD_MAX 280 − 1 − len(X_LINK) 40 = 239` на всё поле, а шапка `mycroft, dev's synthetic ai
co-founder:` + перевод строки занимает 42, значит на мысль остаётся ~197. 08.10 все десять `x`
с первого раза оказались в коридоре 256-295 и переписывались вторым проходом.

Пиши RU и EN версии + короткую версию `x` (тело+ссылка ≤ 280).

Правила голоса: строчными, живо, без длинных тире, без канцелярита. Раскрытие авторства
обязательно первой строкой (§3.3), формулировка «Майкрофт, синтетический кофаундер
оператора. Из корпуса наших дипресёрчей:». **Ничего не выдумывай:** если в карточке нет
результата, бери другой ресёрч, а не додумывай вывод за отчёт.

⚠️ **N БЫВАЕТ НЕИЗВЕСТНО, И ТОГДА ЕГО НЕТ В ТЕКСТЕ** (замер 07.10). Формат требует «от N
ллм», но машинного источника N у ДР до реестра (июнь-август 2026) НЕ существует:
`dr_queue.py status <id>` отвечает `no manifest`, а grep вендорских имён по телу отчёта
считает НЕ рельсы, а упоминания в содержании (у ресёрча про Claude Code «claude» в тексте
есть всегда). Честный выход: строка «от N ллм» идёт только там, где САМ отчёт называет
число («all three vendor reports converged»), иначе заголовок пишется без N. Гейт этого
не требует, так что выдумывать число незачем: 07.10 из 10 тизеров N был доказан у одного.

Сложи в `$IMPORTS_ROOT/content-factory/_dr_lane/teasers-<дата>.json`:

```json
{"date": "...", "teasers": [{"dr_id": "...", "url": "...", "ru": "...", "en": "...", "x": "..."}]}
```

⚠️ Поле `x` — БЕЗ ссылки: гейт сам прибавляет её как 40 знаков (поле ≤239). URL внутри
`x` = ложный перебор лимита (грабля 01.10, три прогона гейта впустую).

`url` бери **программно из `E:/GitHub/deep-research/index.json`**, не с клавиатуры:

## Шаг 3. Гейты (оба обязательны)

```bash
python "$IMPORTS_ROOT/content-factory/dr_teaser_gate.py" check _dr_lane/teasers-<дата>.json
```

Судит длину, живость ссылки (реальный HTTP 200), дедуп по журналу, лимит X, конкретику.
Ненулевой код = не публикуем. **Не заворачивай вывод в пайп** — `| tail` съедает код возврата.

```bash
python "$IMPORTS_ROOT/content-factory/slop_gate.py" --file <тизер.md> --tier dr-teaser
```

⚠️ **По ОДНОМУ тизеру на язык, не по склейке пачки.** Склейка даёт ложный `F6-length-max`:
гейт считает сумму длин вместо одного тела (замер 05.10). Удобно одним скриптом: разложить
каждый `ru`/`en` в свой `.md` в `_dr_lane/_slop/` и прогнать в цикле, собрав сводку.

⚠️ `W4-first-person` и `W3-rhythm` в этой полосе -- ОЖИДАЕМЫЕ WARN, не дефект: тизер ресёрча
пишет про систему, а не про себя. `HB1-unproven-claim` валит на СЛОВЕ «гипотеза» в теле, даже
когда ты сообщаешь, что гипотеза ОПРОВЕРГНУТА (это доказанный результат). Лечится
переформулировкой («расхожее X не подтвердилось», «народная вера»), смысл не теряется.
⚠️ Замер 06.10: правило HB1 ловит русское «гипотеза», но НЕ ловит английское `hypothesis` --
EN-тело с тем же утверждением проходит. Слепая зона гейта, не разрешение писать claim.

Коды slop_gate: `0` OK, `1` WARN (не блокирует), `2` FAIL (блокирует).
Считать любой ненулевой код провалом — ошибка, на ней 21.08 сгорели 20 честных
тизеров.

⚠️ **СТРОЧНЫЙ СТИЛЬ ПРЯЧЕТ ИМЕНА ОТ ПРОВЕРКИ КОНКРЕТИКИ** (замер 07.10). `dr_teaser_gate`

падает с «ни одной цифры и ни одного имени собственного». Лечится не заглавными (голос

⚠️ **`_slop/` НАКАПЛИВАЕТ ЧУЖИЕ ФАЙЛЫ** (замер 07.10): наивный `for f in _dr_lane/_slop/*.md`

Держи ≥35 минут от любого уже стоящего сообщения. Лишнее снимается
`mcp__telegram__delete_scheduled_message` ДО того, как выстрелит.

MCP telegram умеет быть **connected и при этом отбивать ВСЁ**: 07.10 статус был

сперва второй вызов, потом другой инструмент того же сервера, потом статус коннекторов.

Рабочий обход (им 07.10 доставлены все 20 отложенных) СОБРАН И ЛЕЖИТ ГОТОВЫМ:

```bash

python "$IMPORTS_ROOT/content-factory/dr_lane_tg.py" send  <teasers.json> --live
python "$IMPORTS_ROOT/content-factory/dr_lane_tg.py" verify <teasers.json> # второй заход с сервера
```

`send` сам читает очередь и считает бюджет (`10 - занято на сегодня`), остаток кладёт в
раннее окно следующего дня; тест бюджета и слотов -- `_test_dr_lane_tg.py` (красное
доказано на 6 поломках). Потребитель один -- хаб `HUB-01`: сессия @TonySsd и
IP-гейт §7.2 живут только там, на пиры не раскатывается. Внутри -- прямой telethon:

Постановка: `client.send_message(ent, body, schedule=<utc datetime>, link_preview=False)`.
